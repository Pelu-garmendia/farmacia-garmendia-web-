# Farmacia Garmendia — Sitio Web

Sitio web oficial de Farmacia Garmendia, Laferrere, Buenos Aires.

## Archivos
- `index.html` — Página principal
- `tienda.html` — Tienda virtual con panel Admin
- `farmaclick.html` — Turnos de guardia La Matanza
- `netlify.toml` — Configuración de Netlify

## Deploy
Conectado a Netlify con deploy automático.
Cada push a `main` actualiza el sitio automáticamente.
